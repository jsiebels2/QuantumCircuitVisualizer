# QuantumCuircuitVisualizer
A quantum circuit visualize that supports drag and drop functionality for the gates onto the quantum circuit. Provides real time visualization of the resulting state vector. The application is currently extremely limited, as it accomplished everything I needed it to and wanted to move onto projects I find a bit more interesting. Feel free to toy around with it.

## Tech Stack
- React + TypeScript + Tailwind (frontend)
- Flask + Qiskit Aer (backend)

## Running locally
\```bash
# Backend
conda activate quantum-viz
python app.py

# Frontend
cd frontend/react
npm run dev
\```
